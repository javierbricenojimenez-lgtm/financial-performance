# Cierre de la versión analítica 1

- Diagnóstico global y puente exacto de la variación de utilidad (-$3M).
- Categorías y productos prioritarios, con compensaciones y residual visible.
- Investigación de Cajas archivo pack: meses, cantidades, ingreso/costo unitario, devoluciones y clientes.

## Decisiones y pendientes explícitos

El usuario autorizó completar la entrega con el criterio del analista. Se eligió un dashboard HTML local para entregar una vista funcional sin depender de Power BI; el archivo PBIX y el libro Excel no forman parte de esta versión. No se ha ejecutado una implementación empresarial. GitHub queda para después del cierre local, conforme a la instrucción del usuario.

No se confirmó el motivo comercial de no compra o devolución porque la base no lo contiene. Se documentaron las fuentes adicionales necesarias. Los escenarios son supuestos ilustrativos. La calibración de datos sintéticos limita inferencias causales. Estas limitaciones acompañan las conclusiones y no se sustituyen por causas fabricadas.
